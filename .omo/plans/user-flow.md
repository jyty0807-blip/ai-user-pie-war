## 3. 크로스 페이지 유저 플로우

### 3.1 데이터 출처 확인 흐름
```
[모든 페이지] → [? evidence 아이콘 호버]
  → 툴팁: 데이터 출처 + 방법론 요약
  → [자세히 보기 링크] → [/dashboard/onboarding]
```

### 3.2 전문 용어 이해 흐름
```
[모든 페이지] → [ⓘ metric 툴팁 호버]
  → 툴팁: 용어 설명 (WAU/CAC/ROAS/CPM 등)
  → [자세히 보기 링크] → [/dashboard/onboarding]
```

### 3.3 회사 리포트 흐름
```
[대시보드 메인] → [회사 pill 버튼 클릭]
  → Dialog: 회사별 종합 리포트
  → [각 섹션 스크롤] → 개요/유저/마케팅/가격/이슈/전망
```

### 3.4 뉴스 → 상세 정보 흐름
```
[뉴스 탭] → [뉴스 카드 클릭]
  → 외부 링크 (새 탭): 원문 페이지
  → [접이식 링크] → 전체 뉴스 목록 → 외부 링크
```

## 4. 사용자 시나리오 검증

### 4.1 신규 방문자 (AI 비전문가)
```
1. Landing Page 도착 → 서비스 목적 이해 ✅
2. 🗂️ 목차에서 "대시보드" 클릭 ✅
3. KPI 탭에서 💡 한줄요약 읽고 전체 그림 이해 ✅
4. [?] 아이콘 호버로 데이터 출처 확인 ✅
5. ⓘ 툴팁으로 WAU/CAC 용어 이해 ✅
6. [성장률] 토글 → Anthropic 성장 가시화 ✅
7. 📅 업데이트 일정 칩 클릭 → 갱신 주기 확인 ✅
```

### 4.2 면접관 (기술/마케팅 리더)
```
1. Landing Page → 서비스 철학 확인 ✅
2. 회사 리포트 버튼 클릭 → Anthropic 리포트 ✅
3. 타임라인 스토리 → QuitGPT → IPO 연결성 확인 ✅
4. 플랫폼 비교 탭 → SWOT 분석 ✅
5. 온보딩 페이지 → 데이터 윤리 6원칙 확인 ✅
6. 라이브 URL → 실제 배포 확인 ✅
```

### 4.3 데이터 분석가
```
1. 대시보드 → KPI 카드 (추정) 레이블 확인 ✅
2. 온보딩 → 데이터 출처 14개 확인 ✅
3. [?] evidence 아이콘 → 각 데이터 근거 확인 ✅
4. 방법론 4단계 검토 ✅
5. 면접 포트폴리오 고지 확인 ✅
```

## 6. 유저 플로우 검증 리포트

### 6.1 자연스러움 체크 ✅
| 항목 | 상태 | 코멘트 |
|------|------|--------|
| Landing → Dashboard 진입 | ✅ 자연스러움 | CTA 버튼 명확, 목차에서 바로 이동 가능 |
| Dashboard 탭 간 이동 | ✅ 자연스러움 | 탭 구조로 직관적, pill 스타일로 현재 위치 명확 |
| KPI → 비교표 → 스토리 | ✅ 논리적 흐름 | 숫자 → 비교 → 맥락 순으로 자연스러운 정보 계층 |
| 뉴스 → 외부 링크 | ✅ 자연스러움 | 한국어 제목으로 내용 파악 후 원문 이동 |
| 플랫폼 비교 → SWOT | ✅ 자연스러움 | 카드 클릭 → 상세 패널로 깊이 있는 정보 |
| [?] → 온보딩 | ✅ 자연스러움 | evidence 툴팁 → "자세히 보기" 링크로 연결 |
| 리포트 Dialog → 섹션 | ✅ 자연스러움 | 스크롤 가능한 패널, 6개 섹션으로 구성 |

### 6.2 개선 권장 사항
| 항목 | 우선순위 | 제안 |
|------|---------|------|
| 모바일 탭 접근성 | Medium | 탭이 많을 경우 가로 스크롤 힌트 추가 |
| Dialog 닫기 UX | Low | 키보드 Escape 키 지원 확인 |
| 외부 링크 새 탭 | ✅ 이미 구현 | target="_blank" + rel="noopener noreferrer" |
| 데이터 업데이트 시간 | ✅ 이미 구현 | 푸터 "마지막 업데이트: 2026년 7월 25일" |
| 접근성 | Medium | 스크린리더 aria-label 추가 검토 |
